# How to document
1. Add your documentation in the docs folder as markdown files.
2. Add references to the markdown files in the mkdocs.yml file.
3. Push your changes

## Dev setup
Simply setup a python env (3.10 works) and install
```bash
pip install mkdocs mkdocs-material pymdown-extensions mkdocstrings-python mkdocs-jupyter jupyter
```

In the directory you can run `mkdocs serve` and there will be a dev server launched on you system.
Once everything looks good just commit and push.
